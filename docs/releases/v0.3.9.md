# chakra v0.3.9

This release covers 4 merged PRs since v0.3.8. We cut it mostly so Declaire can run Qwen on llama-server through a chakra agent and get its tool calls. Every change adds a field, a type or a target, and nothing existing changes shape, so it stays a patch on the 0.3 line.

Every module is tagged at v0.3.9, and the sibling modules require each other at v0.3.9. Most modules now require mcpkit v0.8.22, with servicekit v0.2.5.

## Added

### Local models
- `OpenAIConfig.TextToolCalls` reads tool calls a model writes as text (PR 360, `declaire#378`). Qwen2.5-Coder on llama-server writes each call as a JSON block in its reply, and the server passes it on as plain content. The Runner saw an answer with no tool call, and the turn ended. With the field set, a call counts in a fence (unlabelled, `json` or `tool_call`), in `<tool_call>` tags, or bare as the whole reply. Text before the first call stays the message's text. Text after it goes, since the model wrote it before the call ran. Streaming holds back only what could start a call. `NewLlamaCppProvider` turns it on.
- llama.cpp and Ollama connections cap each reply at 4096 tokens, `DefaultLocalMaxTokens`, unless the request or the connection sets a cap (PR 361). A local model that ran on used to write until the server's context filled. One Qwen 32B reply reached 6,600 tokens. `LlamaCppConfig.MaxTokens` and `OllamaConfig.MaxTokens` set it, and a negative value sends no cap. A connection's `maxTokens` in agentchat.json now reaches both. `OpenAIConfig.MaxTokens` is the default for any OpenAI-wire request that sets none.

### eval
- `eval.Ladder` runs one set of cases across a series of configs, where each step builds on the steps before it (PR 363, issue 350). `LadderReport.Table()` prints a row per step with cases passed, the change over the step before, and dollars and seconds per correct answer. A failed `Configure` ends the climb, and the later steps say why. `SuiteReport` gains `TimePerCorrect`.
- `make exercise-agents` prints every ladder's table, and `LIVE=<connection> PROFILE=<agentchat.json>` runs one on a real model. `examples/agents` holds the ladders, starting with `calc`.

## Fixed
- The ladder table prints dollars to two significant figures, so a cheap model's cost per correct answer no longer reads `$0.0000` (PR 364). `PROFILE=~/...` on `make exercise-agents` expands the `~`.
