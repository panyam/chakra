# chakra v0.3.5

This release covers 2 merged PRs since v0.3.4. We cut it so jaala's translator loop can set `GraphQuery.FirstStuck`, the next step on mission issue 299, and so Declaire's benchmark driver can read cost from `agentchat exec`. Both add API and change nothing existing, apart from one new exit code in `agentchat exec`. So we kept it a patch on the 0.3 line.

Every module is tagged at v0.3.5, and the sibling modules require each other at v0.3.5. It builds against mcpkit v0.8.20, oneauth v0.3.2 and servicekit v0.2.2.

## Added

### Stuck detection
- `CollapseStuckSteps(key)` is a `StuckPolicy` that sends the next model call a view with each repeated step after the first removed, along with its results (PR 331, issue 330). The record, `TurnResult` and the RunStore keep every step. It re-keys steps with the detector's key, so different drafts that hit the same error stay. A step is removed only when its results follow it in the view exactly, so no tool result loses its call.
- `presets.GraphQuery.FirstStuck` runs on the stuck detector's first finding, before the note and the nudge temperature. Nil keeps the old behavior. `CollapseStuckSteps(StuckKey)` is the usual value.

### Host
- `ConnectionConfig.Price` sets a connection's price in US dollars per million tokens (input, cached input, output), and `ConnectionConfig.Cost` prices one usage report with it (PR 328, issue 327). A connection with no price reports an unknown cost rather than zero.

### agentchat
- `agentchat exec --json` writes three new frames (PR 328). `run-start` comes first and names the connection, model, servers, step cap, approval mode and any `AGENTCHAT_` variable set. `cost` follows each model call. `summary` comes last on every exit, with model calls, tool calls by name, denied calls, tokens by connection, dollars and the exit code. It counts sub-agents and the structured finalize call.
- `examples/benchmark` holds three arms that differ only in the model: gpt-5.5 on `openai-responses`, Sonnet on `anthropic`, and llama.cpp.

## Changed
- An empty `GraphQuery.StuckNote` result now adds no message, so a `FirstStuck` can replace the note (PR 331).
- `agentchat exec` exits 5 when the model connection or a configured MCP server can't start (PR 328). Before, a server that was down left the run answering without its tools, and exec exited 0.

## Notes
- Anthropic bills cache writes above the input rate, and `Usage` has no field for them, so `Cost` comes out a little low for a Sonnet call that writes the cache. Issue 329 tracks it.
- `CollapseStuckSteps` removes messages from the middle of the history for one call. That ends a prompt cache at that point, so llama.cpp re-reads the rest of the prompt, and a Responses connection sends the full history for that call.
