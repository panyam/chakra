# chakra v0.3.8

This release covers 3 merged PRs since v0.3.7. We cut it mostly so Declaire can build providers from a profile with chakra's own builder rather than its copy, which had drifted. It adds a package and changes nothing existing in shape. host keeps every name it had, as aliases. So it stays a patch on the 0.3 line.

Every module is tagged at v0.3.8, and the sibling modules require each other at v0.3.8. It builds against mcpkit v0.8.21 and servicekit v0.2.5.

## Added

### connection
- A new package, `github.com/panyam/chakra/connection`, holds the connection-to-provider builder that used to live in host (PR 357, issue 347). It has `Config`, `Price`, `ThinkingHint`, `Build`, `Types`, `Options`, `ResolveBaseURL` and `BuildEmbedder`. It needs only the root module, so a program that builds providers from an agentchat.json connection no longer imports host and its servers. That's 49 packages rather than 101.
- `connection.Row`, `connection.Router` and `connection.TableRouter` pick connections for a task from how each one has done on that kind of task, and at what cost (PR 358, issue 348). A row records one connection's outcomes, dollars, tokens and seconds for one arm and one tag. `TableRouter` scores each connection's pass rate over the task's tags, less a cost knob times dollars per case. A tag with fewer than `MinCases` cases falls back to the connection's whole-set row. Dollars recorded in a row win over the connection's `Price`, and a connection whose cost is unknown goes after the known ones when cost matters. Nothing in chakra calls the router yet.

## Changed
- host's `ConnectionConfig`, `Price`, `ThinkingHint`, `ProviderBuilder` and `ConnectionTypes` are now aliases of the `connection` types, and `DefaultProviderBuilder` and `BuildEmbedder` call into it (PR 357). Code that uses them compiles unchanged. The builder's errors now start `connection:` rather than `host:`.

## Fixed
- `BuildEmbedder` sends a key set on the connection's `APIKey`, as the chat builder does (PR 357). It used to read only `APIKeyEnv`, so an agentweb embedder whose key came from the browser went out with no key.
- `ext/exec`: a command that starts a daemon, such as nginx or `websockify -D`, now returns (PR 346, issue 345). The daemon left the process group and kept the output pipe open, so the command waited past its timeout and never returned. Both the one-shot path and `exec_command`'s pipe path now stop waiting shortly after the command exits, and the one-shot result says a background process still held the output.
