# chakra v0.3.4

This release covers 1 merged PR since v0.3.3. We cut it so jaala can build its translator loop from `presets.GraphQuery`, which is the last step of mission issue 299. The preset is a new package, and nothing existing changes. So we kept it a patch on the 0.3 line.

Every module is tagged at v0.3.4, and the sibling modules require each other at v0.3.4. It builds against mcpkit v0.8.20, oneauth v0.3.2 and servicekit v0.2.2.

## Added

### Presets
- `presets.GraphQuery` builds a `RunnerConfig` for a model that answers a question by looking at data and writing a query under a grammar (PR 326, issue 300). The host passes its provider, instructions, grammar, tools, retrievers, ledger and check. `Config()` wires them with these defaults:
  - Temperature 0 and 512 max tokens. The temperature goes out only when the provider takes one.
  - DRY penalties, filtered by `Capabilities.Sendable`.
  - The grammar as `ResponseGuided`, only when the provider can send one.
  - The repeat cache for idempotent tools.
  - A stuck detector at 2 repeats, 2 alternations and a 6-step window. Its first finding adds a note and temperature 0.7 for one call. A later finding takes the tools away and asks for the answer, unless the host sets `StillStuck`.
  - No tools after 8 steps spent calling them.
  - 12 steps a turn.
  - Retrieval, ledger and stuck notes all go as the user's message.
- `GraphQueryTuning` holds the numbers with JSON tags, so a host loads them from its own config. A zero field keeps the default.
- `presets.Replace` and `presets.Remove` change one of the preset's stages by its exported name. A host appends its own stages to `StepStages`.

## Dependencies
- mcpkit v0.8.19 to v0.8.20 across every module, with its sub-modules in lock-step (PR 326).
